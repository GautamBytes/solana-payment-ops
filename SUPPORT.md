# PayOps support

PayOps is an open-source project maintained in public. Choose the path that
matches what you need so the request carries enough context to act on.

## Ask a usage question

Use the [question issue form](.github/ISSUE_TEMPLATE/question.yml) for setup,
integration, architecture, or package usage questions. Include the package and
version you are using, the result you expected, and a minimal sanitized example
when possible.

## Report a reproducible bug

Use the [bug issue form](.github/ISSUE_TEMPLATE/bug.yml). Search open and closed
issues first, then include exact reproduction steps, versions, and relevant
sanitized logs. Never post private keys, seed phrases, credentials, customer
payment data, or private merchant reports.

## Propose an improvement

Use the [feature issue form](.github/ISSUE_TEMPLATE/feature.yml). Describe the
payment-operations problem, the outcome you need, and why existing behavior is
insufficient. A focused problem statement is more useful than a large solution
proposal.

## Report a security vulnerability

Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability
reporting. Do not disclose suspected vulnerabilities in a public issue.

## Support expectations

Support is best effort and has no guaranteed response or resolution time.
Hosted deployments, public packages, and repository issues do not include a
service-level agreement. Maintainers may close requests that cannot be
reproduced, are outside the published project boundaries, or expose sensitive
data.
